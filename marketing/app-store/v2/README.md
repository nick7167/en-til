# App Store creative v2

This revision responds to the first review: it removes the numbered labels and replaces the repeated heading/screenshot template with six different illustrated compositions.

Each card uses a full-bleed game scene, short Danish benefit copy, real native UI as a floating card, and characters that interact with the UI. The sequence is: gather the group, answer, back a friend, move on the board, race to the finish, and play again.

The six files are 1320 × 2868 px JPGs for the 6.9-inch iPhone slot. They are drafts and remain separate from the Xcode project and App Store Connect listing.
