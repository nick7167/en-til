# Hosted native checkpoint (not started)

`codemagic.yaml` is a manual-only unsigned build/test workflow pinned to Xcode 26.6 (17F113), iPhone 17 / iOS 26.5, per https://docs.codemagic.io/specs-macos/xcode-26-6/ checked 10 September 2026. It builds the committed XcodeGen project, runs contract/UI tests and exports screenshot attachments. No App Store Connect integration, signing secrets, TestFlight publication or automatic build triggers exist.

The first checkpoint requires explicit permission to create/push a private project repository and connect/start the existing Codemagic account. It may consume included build minutes. Do not start it simply because credentials exist. Review the build result before preparing signing or TestFlight.

Screenshot fixture mode is DEBUG-only and loads public server snapshots generated by scripts/make-fixtures.ts. It never uses an online service or grants production entitlements. These screenshots validate screen construction, not live networking. After visual review, run an independent live service/device test.

Remaining native matrix: small iPhone plus larger device, iOS 18 minimum runtime, accessibility text sizes, VoiceOver, reduced motion, mute, real hardware haptics/audio, eight-player/long-name layouts, and comparison against every approved concept. No test result is established until the hosted run completes.

Signing/TestFlight workflow must be finalized after a real bundle identifier, Apple team, App Store record, backend endpoint and explicit upload permission are provided. No placeholder production resources are created by this repository.
